# Security Policy

## Supported Versions

Active development and security updates target the `main` branch of `Ali-1365/forsakringskassan`.

## Data & Local Artifacts

- Do not commit case files, personal data, or local secrets/configurations to the repository.
- Local runs, analysis outputs, and machine-specific overrides (`_analyserat/`, `output/`, `config/*.local.*`, `.env*`) are ignored via `.gitignore`.

## Reporting a Vulnerability

If you discover a security issue in the repository code or configuration handling, report it via GitHub Security Advisories or directly to the repository maintainer (`Ali-1365`) rather than opening a public issue with sensitive details.
