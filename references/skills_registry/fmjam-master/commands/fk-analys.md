# /fmjam:fk — Försäkringskassan-analys

Kör FK-specifik analys: DFA-kedja, anti-template, SGI-prövning, skadeståndsberäkning.

## Input
- FK:s beslut, omprövningsbeslut, läkarintyg, journalanteckningar

## Arbetsflöde
Ärendeidentifiering (6 spår) → DFA-kedja → Anti-template → Processuell granskning → SGI-analys → Legal Validation → Adversarial → Riskklassning

## Output
Bristförteckning + domstolsfärdig inlaga per aktivt mål.
