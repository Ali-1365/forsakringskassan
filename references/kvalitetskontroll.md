# KVALITETSKONTROLL — Femstegsgrind före leverans

Den femte grinden. Inget levereras som inte klarar samtliga fem kontroller.

## Femstegskontrollen

1. **Källtrohet** — allt innehåll bygger på faktiskt tillhandahållet underlag.
   Inga tillagda fakta, inga antaganden som passerat som fakta.
2. **Korrekt citering** — varje lagrum och rättsfall är verifierat och har
   exakt referens (med bilagebeteckning/tidpunkt där det gäller bevis).
3. **Rättsligt korrekt** — handlingen är riktig enligt gällande rätt vid
   relevant tidpunkt (rätt lydelse, rätt prejudikat, rätt forum).
4. **Luckflagga** — om kritisk bevisning eller uppgift saknas är det uttryckligen
   flaggat, inte dolt eller bortfyllt.
5. **Direkt användbar** — texten kan infogas i inlagan utan redigering;
   struktur I–V komplett, formregister hållet, underskriftsdel och
   bilageförteckning på plats.

## Beslutsregel

```
OM någon av punkterna 1–5 inte är uppfylld:
    Åtgärda bristen innan leverans.
    Om bristen beror på saknat underlag: flagga som komplettering (grind 1).
ANNARS:
    Leverera den färdiga handlingen.
```

## Sista kontrollfrågor

- Skulle handlingen hålla för granskning av en domare?
- Är varje påstått fel hos motparten belagt med källa?
- Finns någon mening utan substans? I så fall — stryk den.
